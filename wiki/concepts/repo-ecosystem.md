# Repository Ecosystem

The Hermes repository is larger than the core runtime. It includes a broad ecosystem around the main agent engine.

## Major non-core buckets
- tests
- skills
- optional-skills
- website docs
- plugins
- environments
- cron
- ACP integration

## Why it matters

A complete understanding of Hermes means distinguishing between:
- the architectural spine of the runtime
- product/documentation surface area
- optional extension ecosystems
- tests that define expected invariants
