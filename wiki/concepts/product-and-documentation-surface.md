# Product and Documentation Surface

Hermes is documented like a full platform product rather than a narrow coding tool.

## Major doc surfaces
- getting-started docs
- user-guide docs
- developer-guide docs
- guides and integrations
- reference docs
- standalone specs and migration docs

## Why it matters

The documentation itself is part of the architecture because it defines extension models, migration strategy, product positioning, and contributor workflows.
