# Built-in Skills Taxonomy

The built-in skills corpus spans many categories, including autonomous AI agents, GitHub workflows, productivity, research, media, MLOps, note-taking, gaming, MCP, social media, and more.

## Interpretation

Built-in skills represent the broadly useful, high-frequency workflow layer Hermes wants available out of the box.
